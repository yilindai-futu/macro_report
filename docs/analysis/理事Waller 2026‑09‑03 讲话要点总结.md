
# 理事Waller 2026‑09‑03 讲话要点总结
主题：经济展望与政策沟通评述（路透NEXT访谈）
> 核心立场：通胀仍显著高于2%目标，但初步出现去通胀迹象；9月FOMC（9.15‑16）政策高度取决于8月通胀数据，**数据向好则支持维持利率不变，通胀反弹则支持加息**；经济与就业表现稳健；同时阐述美联储官员三类政策沟通方式。

## 一、实体经济
1. GDP：2026上半年实际GDP年化增速1.8%；私人国内最终购买年化增长3%，内需基本面强劲；预计全年实际GDP略高于2%。
2. 消费：Q2消费回暖，7月零售走弱主要是亚马逊Prime Day移至6月带来的季节性扰动；股市带来的财富效应有望支撑消费。
3. 企业投资：AI算力与数据中心带动高科技投资高速扩张；软件投资并未被AI代码工具压制，维持历史均值附近增长。不认同“AI属于资本密集窄行业、GDP虚高应当剔除”的观点，认为AI投资是真实经济增量，长期仍将发挥作用。7月非制造业PMI新订单继续扩张，供应链约束持续改善。
4. 风险变量：军事冲突、贸易政策、AI是影响物价与经济活动的主要不确定性来源。

## 二、劳动力市场
1. 就业状况：劳动力需求放缓迹象在2025年末之后消退；截至7月月度新增就业平均6万人，接近/略高于劳动力供给增速（移民大幅压低劳动力供给）；失业率4.1%，低于FOMC长期均衡失业率中枢；裁员、初请失业金数据维持低位，就业整体稳健。
2. 影响：就业市场表现良好，**不是当前货币政策决策的主要约束条件**，仅作为通胀研判的宏观背景。

## 三、通胀
1. 当前读数：7月PCE环比+0.2%，核心PCE环比+0.2%；12个月PCE 3.7%、核心PCE 3.3%。
2. 核心观察：近3个月核心PCE通胀3.05%，自2月4.76%持续回落，下降趋势可喜，但距离2%目标仍有距离。**非市场服务价格（估算值而非真实交易价格）贡献了本轮核心通胀近一半涨幅**，剔除该因素后真实底层通胀表现优于核心PCE纸面数据。
3. 即将到来的数据修正：商务部将调整股票交易相关费用统计口径，预计会使12个月PCE通胀下行0.几个百分点，属于统计修正。
4. 通胀上行风险：能源价格再度抬升、AI产业链带来科技品价格压力、关税进一步上调；但关税价格传导基本完成，高能源价格暂未广泛传导至商品服务。经生产率调整后的薪资增速整体与通胀向2%回落的路径相容。
5. 风险警示：长期通胀预期尚未显著抬升，但仍是重要风险，若预期脱锚、通胀改善逆转，FOMC必须采取行动。
6. 观点：12个月滞后通胀数据参考价值有限，重点跟踪近3个月短期通胀趋势。

## 四、货币政策立场（9月FOMC会议）
1. 当前政策：政策仅对总需求形成小幅约束，通胀小幅反弹就可能促使其支持收紧。
2. 条件判断：
    - 若8月通胀延续去通胀进展 → 支持维持联邦基金利率不变；
    - 若8月通胀数据火热、改善为暂时性 → 支持9月FOMC加息，小幅收紧政策以重启通胀回落进程。
3. 就业预期：预计8月就业报告不会出现大幅偏离近期趋势，因此**通胀将是本次会议投票的决定性变量**。

## 五、央行政策沟通三类框架（Waller核心论述）
1. 解释当前决策：说明当下经济条件如何支撑自己的投票（如7月支持暂停加息，是看到经济强劲+初现去通胀信号，选择等待数据验证）。
2. 阐述反应函数（Reaction Function）：**有条件的陈述，不是政策承诺**；说明“如果数据A发生，则我支持政策B”，给市场理解决策的参考，类比棒球裁判的好球带——不需要绝对完美，但规则要稳定可预期。本次讲话就明确了暂停/加息分别需要何种数据条件。
3. 前瞻指引（Forward Guidance）：预设一条基本不受数据扰动的利率路径。**仅适合利率处于有效下限的环境**；举例2021‑2022年，在零利率时期通过前瞻指引提前收紧金融条件；当前环境不适合使用这类前瞻指引。
