# MacroReport AI Agent — 商业计划书

> 美股宏观分析智能体：为中端市场投资者提供机构级、可溯源的宏观研究视角。

---

## 1. 问题陈述

### 市场现状

当前美股宏观分析市场存在明显的两极分化：

| 层级 | 代表产品 | 价格 | 问题 |
|---|---|---|---|
| 机构级 | Bloomberg Terminal、AlphaSense | $12,000–$32,000/年 | 中小机构与个人无法负担 |
| 消费级 | Perplexity Finance、通用 ChatGPT | 免费–$20/月 | 分析深度不足、无机构级数据源 |
| **中端空白** | **无成熟产品** | **$500–$5,000/年** | **市场明显缺口** |

### 核心痛点

1. **割裂的分析链**：没有任何现有产品能将美联储政策 → 经济周期 → 板块轮动 → 期权市场定位一条链连接起来，形成有机的宏观观点
2. **价格壁垒**：Bloomberg 定价使 95% 的潜在用户（RIA、家族办公室、中小对冲基金）无法接触机构级分析
3. **幻觉风险**：通用 AI 工具在金融领域的幻觉率仍高，EY 统计每次 AI 事故平均造成 $440 万损失
4. **时效性问题**：模型训练截止日期导致宏观数据几天内即过时

## 2. 产品定义

### 产品愿景

**MacroReport** 是一个面向美股市场的宏观分析智能体，每日或每周自动生成结构化、可溯源的宏观研究报告。目标用户是需要机构级洞察但无力承担 Bloomberg 授权费的中端市场参与者。

### 核心功能模块

#### 2.1 宏观框架分析（每周更新）

| 分析维度 | 数据来源 | 输出内容 |
|---|---|---|
| 美联储政策 | FRED（联邦基金利率、点阵图）、FOMC 会议纪要 | 利率路径预测、QT 进度、通胀趋势 |
| 经济周期定位 | FRED（GDP、ISM PMI、JOLTS、NFP） | 当前所处周期阶段（早/中/晚/衰退） |
| 收益率曲线 | FRED（2s10s 利差、TIPS breakeven） | 曲线形态判断，金融板块影响 |
| 企业盈利周期 | SEC EDGAR、Quartr 财报数据 | S&P 500 EPS 增速趋势、利润率变化 |
| 板块轮动信号 | ETF 资金流向、板块相对表现 | 当前周期对应的超配/低配板块 |
| 期权市场情绪 | Unusual Whales API | VIX、Put/Call 比率、暗池流向、Gamma 曝露 |
| 地缘政治风险 | 新闻 RAG 检索 | 当前主要风险因素及量化影响评估 |

#### 2.2 每日快讯（Daily Brief）

- 前一交易日关键经济数据解读
- 今日重要数据日历（CPI、非农、FOMC 决议等）
- 期权流向异常信号预警
- 与上期宏观观点的 Delta 对比（有什么变化、为什么）

#### 2.3 可交互问答

用户可针对当前宏观环境提问，系统基于已检索的数据实时回答，所有回答附带数据来源引用。

### 3.2 数据源

| 类别 | 来源 | 接入方式 |
|---|---|---|
| 宏观经济数据 | FRED API（50 万+ 时间序列）| REST API，免费 |
| 财报与基本面 | SEC EDGAR、Quartr、Financial Modeling Prep | REST API |
| 期权市场数据 | Unusual Whales API（100+ 端点） | REST + WebSocket |
| 板块 ETF 流向 | SPDR ETF Flow、ETF.com | REST API |
| 新闻与文档 | 公开新闻 RAG + Fed 声明文本 | 向量检索 |
| 经济日历 | Investing.com、Trading Economics | Scraping + API |
| 预测市场 | Polymarket | REST API |

### 3.3 技术栈

- **后端框架**：FastAPI（与 macro-report 服务共用基础设施）
- **智能体框架**：LangGraph（生产级有向图工作流，支持分支/回环）
- **向量存储**：PostgreSQL + pgvector（复用现有 RDS）
- **调度**：EventBridge → Lambda → ECS Fargate（复用 macro-report 现有模式）
- **LLM 配置**：通过 `llm_configs` + `prompt_bundle` 统一管理（遵循项目 LLM 调用规范）

### 3.4 幻觉防控措施

- 所有输出结论必须附带数据来源引用（FRED 序列名、EDGAR 文件编号、API 端点）
- Critic Agent 在发布前验证数据引用有效性
- 禁止模型凭训练知识推断实时数值，所有数字必须来自工具调用结果
- 每条宏观观点标注数据时效（"数据截至 YYYY-MM-DD"）

## 4. 目标市场

### 主要用户细分

| 细分市场 | 规模 | 当前痛点 | 付费意愿 |
|---|---|---|---|
| **独立注册投资顾问（RIA）** | 美国约 16,544 家注册顾问 | Bloomberg 太贵，通用 AI 不合规 | $200–$500/月 |
| **家族办公室** | 市场规模 $215 亿（2026），83% 视 AI 为优先投资 | 缺乏专属宏观分析工具 | $500–$2,000/月 |
| **小型对冲基金** | 95% 已在使用 AI 某种形式 | 现有 AI 偏向效率，缺宏观 alpha 整合 | $1,000–$5,000/月 |
| **高净值个人/散户进阶用户** | Gen Z/千禧一代中 1/3 已用 AI 做财务决策 | Perplexity Finance 深度不足 | $50–$200/月 |

### 市场规模估算

- 财富管理 AI 市场：$18 亿（2025）→ $146 亿（2034），CAGR 26.2%
- 可服务市场（SAM）：聚焦美国中端宏观分析工具 → 估算约 $5–8 亿年市场
- 初期可占领市场（SOM）：上线第一年目标 500 付费用户 → 预估 ARR $150 万

## 5. 竞争分析

### 直接竞争对手

| 产品 | 优势 | 劣势 | 定价 |
|---|---|---|---|
| Bloomberg Terminal | 数据最全、机构信任度高 | $32,000/年，界面复杂，无宏观链式分析 | $32,000/年 |
| AlphaSense | 文档分析强，7,000+ 企业客户 | 偏 bottom-up，缺实时市场信号 | $12,000/年 |
| Perplexity Finance | 价格低，界面友好 | 宏观深度弱，无链式分析，数据源有限 | $0–$20/月 |
| Kensho (S&P) | 机构数据底层 | 不面向终端用户 | 不公开 |

### 差异化定位

MacroReport 的核心差异在于：
1. **完整宏观链**：唯一将 Fed 政策 → 经济周期 → 板块轮动 → 期权情绪一条线连通的产品
2. **可溯源输出**：每个观点附带可验证的数据来源，适合合规环境
3. **中端定价**：$200–$2,000/月，填补 Bloomberg 与免费工具之间的空白
4. **中文双语支持**：面向华人投资者市场（香港、新加坡、中国大陆出海资金）的本地化优势

## 8. 关键风险

| 风险 | 等级 | 应对措施 |
|---|---|---|
| **AI 幻觉导致投资误导** | 高 | 强制数据引用 + Critic Agent + 免责声明；不提供"买入/卖出"建议 |
| **监管合规（SEC/FTC）** | 中高 | 明确定位为"研究信息工具"而非"投资建议"；所有输出附免责声明 |
| **数据源 API 成本** | 中 | 优先免费 API（FRED、EDGAR），付费 API（Unusual Whales）纳入定价成本 |
| **Bloomberg 降价或推出类似产品** | 低 | 短期内 Bloomberg 无法快速降至 $300/月；我们的竞争护城河在中文化和链式分析 |
| **大模型能力快速迭代** | 低 | 通过 `llm_configs` 抽象层，支持快速切换底层模型 |
